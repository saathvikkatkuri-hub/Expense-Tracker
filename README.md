# Expense Tracker

A Python-based console application for managing daily expenses.

## Features

- Add expenses
- View all expenses
- Update expenses
- Delete expenses
- Categorize expenses
- Calculate total spending
- View category-wise spending
- Store expenses using JSON
- Input validation
- Data persists after closing the application

## Technologies Used

- Python
- JSON
- File Handling

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python exptracker.py
